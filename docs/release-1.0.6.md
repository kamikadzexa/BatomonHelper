# Batomon Helper 1.0.6

- Fixes ally targeting in battle projections. Cairnage no longer gains Damage from its own Shield; abilities that explicitly say “This and …” still include their caster.
- Updates wiki imports to use the `/wiki` home route while retaining the catalog routes and falling back to the site root for Steam build metadata when needed.
- Adds a saved **Always on top** option in Game setup. It is enabled by default and can be toggled at any time.

Install `BatomonHelper-Setup-1.0.6.exe` and verify its accompanying SHA-256 checksum. Requires Windows 11 22H2 or newer, x64. The installer is unsigned.
