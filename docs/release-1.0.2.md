# Batomon Helper 1.0.2

Windows x64 helper release. Run `BatomonHelper-Setup-1.0.2.exe`; verify it using the accompanying SHA-256 checksum.

- Refreshes the bundled game reference to Balance 25, Steam build 25738032.
- Bundles the current 148-creature catalog directly rather than reporting the historical Balance 24 baseline with a reference overlay.
- Keeps the current game setup, bridge management, updater, and live-board improvements.
- Fixes Battle Insights flashing and restarting analysis on unchanged bridge heartbeats and setup checks, including during battles.

Requires Windows 11 22H2 (build 22621) or newer, x64. Training Lab is excluded. The installer is unsigned.

After installation open **Game setup**, confirm the folder, install the mod with the game closed, then select **Launch game**. Catalog browsing works without the game. Remove the bridge through Game setup before uninstalling the helper if you want both removed.

Battle WIN/LOSS comes from the game. Output projections and positioning suggestions are estimates.

See [validation results and remaining manual checks](release-validation.md).
