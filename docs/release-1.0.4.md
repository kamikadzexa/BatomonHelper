# Batomon Helper 1.0.4

Updates the offline reference and combat projection data for Balance 26, Steam build 26078162 (game 1.4.0), imported from https://batomon.com/wiki on 2026-10-23.

Installer updated on 2026-10-23 with **Bridge 1.5.1**, fixing the GDScript compile error that prevented Bridge 1.5.0 from starting. If you downloaded the earlier 1.0.4 installer, download this replacement and its new checksum, reinstall, then use **Game setup → Update/repair mod** with the game closed. Same-version replacements require a manual download.

- Adds Witch, her portrait and ability, and 15 potion items (25 trainers, 55 items, 93 trinkets, 148 creatures).
- Refreshes normal/shiny stats, cooldowns, costs, abilities, region membership, and trainer/item reference text. Includes the Bug Catcher discount and Mystic Pearl healing changes.
- Furnadon projections now scale Burn with the number of different trinkets, counting duplicate copies once.
- Supports the wiki's new page format and verifies its shared full-level snapshot against the catalog build and balance.
- Includes Bridge 1.5.1 and run-capture improvements: saved runs contain battle-start teams, game outcomes, and sampled battle state for later simulator comparisons. Update/repair the bridge with the game closed to enable samples.

Run `BatomonHelper-Setup-1.0.4.exe` and verify it with the accompanying SHA-256 checksum. Requires Windows 11 22H2 or newer, x64. The installer is unsigned.

Battle output and placement advice remain passive-target estimates. Training Lab is excluded from the installer; its potion/shop rule audit is not complete for Balance 26. Existing strategy observations and historical source reviews retain their original provenance.
