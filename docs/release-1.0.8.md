# Batomon Helper 1.0.8

- Updates the offline catalog and combat rules to Balance 28, Steam build 26773903.
- Improves combat projections for simultaneous casts, Battle Start effects, percentage bonuses, cooldown overflow, and overlapping multicasts.
- Moves the placement objective selector to the top right of the Placement panel and makes the full control clickable.
- **Most HP + shield** ranks layouts by survival, then 30-second DPS, then the number of creatures on the board.
- Bridge 1.8 buffers more combat observations, including changes around Battle Start and the end of playback. Run validation reports gaps and the first difference by slot.

Existing installations can use **Check for updates** in **Game setup**. After updating the helper, close the game and choose **Update/repair mod** to upgrade the bridge. The installer requires Windows 11 22H2 or newer on x64 and is unsigned.
